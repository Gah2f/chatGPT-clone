**ChatGPT UI Clone 🤖**
**Description**

A sleek and responsive ChatGPT UI clone built with React and Tailwind CSS. It replicates the core chat interface of ChatGPT with a modern sidebar, input functionality, and dark theme styling. Ideal for experimenting with OpenAI’s API or creating your own chatbot frontend.

**Why I Built This Project**

I built this project to practice frontend development while exploring AI integrations. By replicating ChatGPT’s interface, I learned how to design intuitive UIs, handle chat interactions, and prepare a solid frontend for AI-powered applications.
